Defines the write half of a repository for entities of type TEntity.

public interface IWriteRepository<TEntity> where TEntity : class

Type Parameters

TEntity

The type of the entity for which the repository provides write access.

Remarks

The entity based methods stage their change in the change tracker and take effect on the next save operation, which is the caller's responsibility. The Execute prefixed methods execute immediately and bypass the change tracker entirely, so no interceptor runs for them.

Delete(TEntity) and Update(TEntity) have no asynchronous counterpart, because marking an entity in the change tracker is a synchronous in memory operation with nothing to await. Call them and then await the save operation. The exception is CreateAsync(TEntity, CancellationToken), which does await when the entity uses a value generator that queries the store.

Depend on this rather than on IGenericRepository<TEntity> wherever a component only writes, such as an importer or the command side of a CQRS split.

ExecuteDelete(Expression<Func<TEntity, bool>>)

Deletes all database rows for the TEntity instances which match the expression from the database.

int ExecuteDelete(Expression<Func<TEntity, bool>> expression)

Parameters

expression Expression<Func<TEntity, bool>>

The condition to fulfill to be deleted.

Returns

int

The total number of rows deleted in the database.

Remarks

This operation executes immediately against the database, rather than being deferred until save changes is called. It also does not interact with the EF change tracker in any way: entity instances which happen to be tracked when this operation is invoked aren't taken into account, and aren't updated to reflect the changes.

This deletes permanently, even for soft deletable entity types. Because no save operation takes place, save changes interceptors never run, and the soft deletable interceptor therefore cannot turn the deletion into a flag update. The rows are gone. Use Delete(TEntity) together with a save operation to soft delete.

Defines the write half of a repository for entities of type IIdentityEntity<TKey> with a primary key of type TKey.

public interface IWriteIdentityRepository<TEntity, TKey> : IWriteRepository<TEntity> where TEntity : class, IIdentityEntity<TKey> where TKey : IEquatable<TKey>

Remarks

Extends IWriteRepository<TEntity> with key based bulk operations. Every method declared here executes immediately and bypasses the change tracker, so no interceptor runs for any of them.

ExecuteDelete(IEnumerable<TKey>)

Deletes all database rows for the TEntity instances which matches the ids from the database.

int ExecuteDelete(IEnumerable<TKey> ids)

Parameters

ids IEnumerable<TKey>

The primary keys of the TEntity.

Returns

int

The total number of rows deleted in the database.

Remarks

This operation executes immediately against the database, rather than being deferred until save changes is called. It also does not interact with the EF change tracker in any way: entity instances which happen to be tracked when this operation is invoked aren't taken into account, and aren't updated to reflect the changes.

This deletes permanently, even for soft deletable entity types. Because no save operation takes place, save changes interceptors never run, and the soft deletable interceptor therefore cannot turn the deletion into a flag update. The rows are gone.

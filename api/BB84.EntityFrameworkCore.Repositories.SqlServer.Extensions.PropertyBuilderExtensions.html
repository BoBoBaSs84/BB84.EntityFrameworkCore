Remarks

The PropertyBuilderExtensions class provides extension methods that allow developers to specify the SQL Server data type for a property when using Entity Framework Core to map their domain models to the database. Each method configures the column type for the property being built, enabling precise control over the database schema.

Every method comes in two forms. The generic form extends PropertyBuilder<TProperty> and returns it unchanged, so the property type survives the call and anything typed further along the chain — HasDefaultValue, HasConversion, HasValueGenerator — stays compile-time checked. The non-generic form exists for the Property(string) path used by shadow properties, where no property type is available.

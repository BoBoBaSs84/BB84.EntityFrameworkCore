Defines the read half of a repository for entities of type IIdentityEntity<TKey> with a primary key of type TKey.

public interface IReadIdentityRepository<TEntity, TKey> : IReadRepository<TEntity> where TEntity : class, IIdentityEntity<TKey> where TKey : IEquatable<TKey>

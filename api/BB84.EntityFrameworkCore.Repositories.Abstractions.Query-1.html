Describes how a read operation composes its query: what to filter by, what to include, how to order, how much to skip and take, and how to treat tracking and query filters.

Remarks

Every option is optional. An instance with nothing set means "everything, untracked, with the global query filters applied", so passing no query at all reads the whole set.

The options are applied in a fixed order: Where, QueryFilter, IgnoreQueryFilters, Include, OrderBy, Skip, Take. Ordering therefore happens before paging, which is the only combination of the two that is meaningful. 

IReadOnlyList<PersonEntity> people = await repository.GetListAsync(
    new()
    {
        Where = x => x.IsActive,
        OrderBy = q => q.OrderBy(x => x.LastName),
        Include = [x => x.Jobs],
        Take = 50,
    },
    cancellationToken);

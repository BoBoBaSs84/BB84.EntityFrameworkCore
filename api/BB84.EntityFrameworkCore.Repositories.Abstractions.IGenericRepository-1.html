Remarks

The composition of IReadRepository<TEntity> and IWriteRepository<TEntity>, and the interface a repository implementation declares. It adds no members of its own.

Depend on one of the halves instead wherever a component only reads or only writes; the dependency then states in its type what it is allowed to do.
